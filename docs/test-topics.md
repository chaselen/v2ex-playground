# 话题测试样本

本文记录具有稳定测试特征的公开 V2EX 话题，供手动回归和 Agent 选择真实页面集成测试样本。最后核对日期为 2026-07-16。

V2EX 页面内容、回复数量和可访问状态可能变化。新增自动化断言时，应优先断言结构或下限，不要依赖点击数、感谢数等持续变化的数据；若样本失效，应更新本文并同步调整对应测试。

## 使用方式

- 手动测试：运行“打开帖子”命令，输入下表中的话题 ID 或完整链接
- 真实页面测试：通过 `V2exClient.getTopicDetail(id, page?)` 获取内容，并保留 `Accept-Language: zh-CN,zh;q=0.9`
- 内容渲染回归至少覆盖亮色、暗色和高对比主题；涉及图片时同时切换“查看帖子时显示图片”设置
- 若测试依赖登录后的收藏、感谢或回复能力，使用自己的测试账号，不把动态操作结果写成公共样本的固定断言
