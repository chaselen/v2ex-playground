# 官方个人主页设置兼容边界

契约来源：[V2EX 个人主页设置](https://www.v2ex.com/settings/profile)。2026-10-20 使用登录账号临时切换显示开关、自定义首页、CSS 和时区，并在完成后逐项恢复。下表区分真实页面验证和现有调用链结论；不将页面返回的隐藏金额解释为真实零余额。

| 设置                                    | 对插件的影响及兼容方式                                                                                                                                          | 验证依据                                     |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| 显示余额                                | 关闭后右栏 `.balance_area` 消失，概览以 `showBalance` 标记可见性；「我的」显示余额入口，详情仍从 `/balance` 主区读取真实金额                                    | 开关切换、账户及余额 live 测试               |
| 显示首页节点导航                        | 开启后增加首页底部节点目录；列表根据包含 `.cell.item` 的盒子定位                                                                                                | 开关切换、首页 live 测试及盒子顺序回归测试   |
| 节点图标作为 favicon                    | 关闭后主题页只返回站点图标；面板回退到既有节点头像代理。解析优先选取节点 navatar                                                                                | 开关切换、主题 live 测试和图标解析测试       |
| 使用高精度头像                          | 解析读取页面实际 avatar 地址，不依赖尺寸后缀；当前页面切换后仍可能返回 xlarge                                                                                   | 开关切换、真实列表与右栏 DOM                 |
| 在首页显示收藏节点                      | 只改变首页附加节点区域；插件收藏来自 `/my/nodes`，节点全集来自 API                                                                                              | 开关切换及调用链检查                         |
| 自定义首页跳转                          | `/` 会跳转，设为 `/notes` 后没有账户侧栏；登录检查、退出入口获取、概览与在线人数刷新均请求 `/?tab=all`                                                          | 实际跳转验证、登录及账户 live 测试、单元回归 |
| 使用自定义 CSS / 自定义 CSS             | 站点把 CSS 注入完整文档，插件只解析业务片段，不加载原站 head 样式，继续采用 VS Code 主题                                                                        | 注入标记 CSS、真实 HTML 与渲染调用链检查     |
| 正文英文字体                            | 属于原站文档样式，插件使用自己的主题字体                                                                                                                        | 调用链检查，未单独切换字体                   |
| 时区                                    | 页面部分展示时间会随时区变化，已观测到 `-04:00`；主题发布时间 title 和余额流水在本次样本中仍为 `+08:00`。签到任务日优先读取流水描述中的任务日，不用显示日期推断 | 临时切换 America/New_York，检查主题及流水    |
| 签名 / 个人简介                         | 签名由账户侧栏和用户页读取；简介由用户 API 的 bio 读取                                                                                                          | 现有类型、解析和 API 调用链检查              |
| 个人网站 / 所在公司 / 工作职位 / 所在地 | 当前插件未展示这些字段，不参与登录或列表解析                                                                                                                    | 调用链检查，未改写个人资料                   |
| 状态更新查看权限                        | 作用于原站状态更新；插件当前没有状态更新页面                                                                                                                    | 调用链检查，未切换权限                       |
| 社区财富排行榜                          | 控制公开排行参与；插件不读取财富排行榜，与右栏余额开关分离                                                                                                      | 调用链检查，未切换以公开资产                 |

账号名、邮箱及其修改入口不属于此表的展示选项，本次没有修改。VS Code / Cursor 宿主内面板交互需单独手动回归；HTML 和领域 live 测试不能替代宿主验证。
