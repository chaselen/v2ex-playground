# 提醒消息删除

「我的 → 消息」每条提醒在时间行最右侧提供删除按钮，鼠标移入该条消息或键盘焦点进入时显示；确认框打开和删除期间保持可见，无悬停能力的设备始终显示。按钮预留空间，显示时不挤动正文；使用共享 ConfirmPopover 确认。删除期间禁用消息删除按钮，失败保留原消息并显示错误。

删除使用空请求体的 `POST /delete/notification/{id}?once={once}`，以 HTTP 请求成功作为完成信号。`AccountService.deleteNotification()` 在 POST 前调用由客户端注入的 `getOnce()`，通过 `/poll_once` 获取最新令牌；页面中提取的令牌可能已被发帖等写操作消耗，不用于删除。令牌不向 Webview 暴露，删除请求无需传入列表页码。业务层不自动重试删除；Session 统一处理登录失效与两步验证要求，并在验证完成后重试原请求。

删除成功后移除本地消息并刷新当前页，以补齐列表、总数与分页；当前页仅剩一条且页码大于 1 时，刷新上一页。删除后的刷新失败使用列表原有的重试入口，不再次删除。删除请求结束时比对当前账户，账户不同则忽略旧操作的界面更新。重新加载消息时清除旧删除错误。

真实网页验证只检查消息读取与 once 获取，自动化测试不删除账户的真实消息。
