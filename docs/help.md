# 站点帮助

通过「V2EX: 站点帮助」命令或主视图标题菜单打开帮助面板。目录和正文由 `V2exSession` 实时请求 `/help/{slug}`，保留中文请求头，不要求登录。

解析器读取 `#Navcol .nav` 与 `#Maincol .markdown_body`；不匹配时显示错误，提供重试及浏览器原文入口。原站脚本、表单、事件属性和任意内联样式不会进入 Webview；图片仅保留经过校验的正整数 px 宽高样式，资源地址只允许 HTTP(S)。目录没有静态主题清单。

帮助面板复用一个实例，通过 `ready()` 与状态事件初始化；并发切换主题只接受最新请求结果。点击目录后立即选中目标主题，保留目录并将正文替换为结构化骨架屏；失败时在正文区域显示错误与重试入口。后台保留上次数据仅用于复用目录，旧正文不会作为目标主题显示。帮助页不提供刷新按钮。

帮助正文复用 HTML 内容增强、图片预览和共享链接导航。公共控制器将原站 `/help/{slug}` 链接转到帮助面板；「查看原文」直接调用外部浏览器入口。其他站内链接按共享规则打开话题、用户或节点面板。

帮助页使用两列阅读布局，目录带独立标题、当前主题标记与分隔线；窄窗口目录换行为紧凑按钮。正文统一标题层级、段落行距、列表、引用、代码与可横向滚动表格的排版，首页介绍按原站直属内容块分隔。全部颜色使用宿主语义主题变量。

帮助正文与话题正文共用 `_topic-content.scss` 的 `article` mixin，包括 14px 字号、1.72 行高、标题、段落、列表和代码排版。目录文字与箭头在按钮的 label 容器内使用 flex 垂直居中，箭头固定靠右。

帮助文档的图片采用行内排版，保留原站声明的正整数 `width` / `height`。例如虚拟货币说明中的 `mod@2x.png` 按 30 × 14 显示；高分辨率文件不按原始像素放大，也不因文件名重复折半。图片仍受正文最大宽度约束。

原站正文末尾的 `small` 元信息（最后更新时间与查看次数）使用次级文字色与 12px 字号，与主体内容拉开间距。

节点帮助页的图标通过原站行内 `height: 24px` 等比缩放。图片样式仅提取正整数 px 的 `width` / `height`，其他声明全部丢弃；行内尺寸优先于正文图片的自动高度规则。

## 特殊文档结构

API 文档保留标题 ID 与页内 fragment 链接，帮助页在捕获阶段定位当前正文，避免共享导航将其当作外部链接。原站 `blockquote.f12` 中的请求示例映射为 `help-code-block`，保留多行换行且不叠加行内代码边框；表格的正整数列宽保留。

原站的 `small.fade` 和包含此类元素的 `div.flex-one-row` 分别映射为限定的 `help-muted` 与 `help-page-meta`，兼容单行文末信息及 API 页分列的更新时间、查看次数。其他原站 class 仍被过滤。

真实页面测试动态遍历原站帮助目录的所有主题，核对正文、目录与页内链接目标，并覆盖 API 示例及页脚的语义映射。
